# Changelog

All notable changes to WindowFrame_CC. Format inspired by [Keep a Changelog](https://keepachangelog.com/); versions follow the plugin's own numbering (1.0, 1.1, ... 1.12).

## [1.12] - 2026-10-16
No functional change since 1.11.
- Screenshots added to the README.

## [1.11] - 2026-10-16
First public release on GitHub.
- Rectangular-section frame along the outer outline of curves, surfaces, polysurfaces, extrusions, meshes, SubD and hatches.
- Outputs: Solid, Mitered 45, Mitered 90. Offset: Inside / Outside / Center. Depth direction: Front / Back / Center.
- Separate side / top / bottom widths (or one linked value).
- Grouping options, single-step undo, inputs never modified.
- Per-session log files for diagnosing problems.

## [1.0] to [1.10] - 2026-10-15 to 2026-10-16
Private development versions, not published individually.
